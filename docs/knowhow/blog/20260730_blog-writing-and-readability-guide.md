## 💡 要点・コアコンセプト (Key Concepts / Summary)

- **ブログ執筆の大原則**: 常に **「読者目線であること」**。読者は「流し読み」「モチベーションが低い状態」で訪問するため、ストレスなく理解できる文章と視覚デザインが成功の鍵となる。
- **文章力＆可読性を高める3つの柱**:
  1. **論理的な文章構造（PREP法）**: 結論から伝え、離脱を防ぐ。
  2. **ストレスのない文章ルール**: 漢字比率・一文の長さ・語尾・指示語を整える。
  3. **視覚的デザインの整理**: 装飾・画像・吹き出し・枠線で直感的な理解を助ける。
- **執筆・改善の4ステップ**:
  - `[準備]` ペルソナ選定・構成案作成
  - `[本文執筆]` PREP法・ライティングルール適用
  - `[デザイン視認性]` 画像・装飾・レイアウト調整
  - `[推敲]` 一晩寝かせて別端末（スマホ）で最終チェック

## 🛠 具体例・実践パターン (Examples, Cases & Applications)

### 1. 執筆前の準備・ペルソナ選定

万人に向けた記事は誰の心にも刺さらないため、ターゲット（ペルソナ）は**「特定の1人」**に絞り込む。

- **❌ 悪い例**: 「ブログ初心者」
- **⭕ 良い例**: 「最近ブログを始めたものの、記事が最後までうまく書ききれなくて悩んでいる知人の山田さん」

---

### 2. 論理的で読みやすい文章ルール（文章術）

#### ① 結論から書く（PREP法）

論理的でスッキリした主張を展開するブログライティングの王道フォーマット。

```text
P (Point: 結論)    ─＞ 冒頭で要点・答えを明確に伝える
R (Reason: 理由)   ─＞ なぜそう言えるのか根拠を示す
E (Example: 具体例) ─＞ 数字や事例で理解を深める
P (Point: 再結論)  ─＞ 最後にもう一度強調して定着させる
```

- **接続詞のバリエーション**:
  - **理由**: なぜなら / その根拠は / 理由は / 〜だから
  - **具体例**: たとえば / 具体的には / 例としては
  - **再結論**: そのため / つまり / したがって / ポイントは

#### ② 文章品質を高めるライティングチェックルール

| 項目 | ルール・目安 | 理由・改善例 |
| :--- | :--- | :--- |
| **文字比率** | **漢字 30% / ひらがな 70%** (または カタカナ10%) | 漢字が多いと黒く重い印象になる。「読みづらい」「理解しづらい」など平仮名に開く |
| **一文の長さ** | **40〜50文字以内（1文1メッセージ）** | 長文は読解ストレスを増大させる。接続詞で繋げず句点（`。`）で切る |
| **語尾の重複** | **3回以上の連続NG（上限2回まで）** | 「〜です。〜です。〜です。」は単調。語尾のバリエーション（「〜でしょう」「体言止め」等）を織り交ぜる |
| **語尾の統一** | **「です・ます調（敬体）」で統一** | 「〜である。〜です。」の混用を防ぎ、親しみやすいトーンにする |
| **指示語の削減** | **「これ・それ・あれ」を極力排除** | こそあど言葉は指示対象を探す手間を生む。具体名詞に置き換える |
| **難解語の置換** | **中学生でもわかる言葉に変換** | 専門用語は平易な日常語にするか、直後に初心者向けの補足定義を添える |
| **冗長表現の削減** | **「こと」「という」等を削る** | ❌「嫌いになることで傷つくことは減る」→ ⭕「嫌いになれば傷つく回数は減る」 |
| **係り受け** | **主語と述語、修飾語を近づける** | ❌「とてもかっこいい三浦さんの息子」→ ⭕「三浦さんの息子はとてもかっこいい」 |

### 3. 視覚的デザインと視認性の向上（デザイン・装飾）

読者の流し読みをサポートし、スクロールを止めさせるデザインルール。

| デザイン要素 | 目的・効果 | 実践ルール |
| :--- | :--- | :--- |
| **1. 箇条書き・表** | 複数要素の整理・比較 | 3つ以上の要素は箇条書き（`<ul>`/`<ol>`）、数値比較は表（`<table>`）化する |
| **2. 装飾の統一** | 意図の明確化・チラツキ防止 | 色ルール（赤＝重要、青＝補足等）を決め、装飾の種類を2種類程度に絞り込む |
| **3. 画像・図解** | 圧迫感の軽減・直感理解 | H2見出し下に画像配置。テキストだけでなく図解・フロー図で休憩ポイントを作る |
| **4. 吹き出し枠** | テンポ創出・会話形式 | 人物対話で読者の疑問を代弁し、長文の箸休め・テンポ調整に使う |
| **5. 改行と余白** | 画面の圧迫感防止 | 段落（トピック）ごとに改行・空行を意図的に挿入（特にスマホ表示を意識） |
| **6. 枠線ボックス** | 重要ポイントの強調 | 最重要注意点やまとめをボックス枠で囲み、スピーディな要点把握を促す |

---

### 4. 執筆後の推敲・チェックフロー

書いた直後は達成感や主観が入っているため、誤字脱字や説明不足に気づきにくい。

- **一晩寝かせる**: 執筆直後の公開を避け、時間を置いて客観的な視点を取り戻す。
- **スマホ等の別端末で確認**: PC執筆時とは異なる画面幅・改行位置で第三者目線で読み返す。
- **音読チェック**: 実際に声を分けて読むことで、引っかかりや係り受けの違和感に気づく。

## ⚠️ 注意点・リスク・懸念事項 (Risks, Trade-offs & Considerations)

- **一度に全テクニックを適用しようとしない**: まずは「PREP法」と「基本ルール（文字比率・一文長）」から定着させる。
- **ひらがな化（開き）のしすぎ**: すべてひらがなに直すと文章が長くなり可読性が落ちる（バランスを調整する）。
- **装飾の過剰使用（チカチカ現象）**: マーカー・吹き出し・太字を多用すると最重要部分が埋もれるため厳禁。
- **ターゲット層に応じた表現調整**: 読者が専門家の場合は用語を排除しすぎると説得力を損なう。
