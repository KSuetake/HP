## 💡 要点・コアコンセプト (Key Concepts / Summary)

- **記事公開前のチェックの重要性**: 原稿を書き上げた直後にそのまま公開せず、必ず事前にチェック（セルフ校正・推敲）を行うことで、記事の品質向上と執筆スキルの上達につながる。
- **公開前チェックを行う3つのメリット**:
  1. **記事の質が向上する**: 誤字脱字の修正や表現の微調整により、読者の離脱を防ぎ、内容理解を促進できる。
  2. **記事を作成するスキルが伸びる**: 自身の書き癖や間違いやすい箇所に気づけるようになり、執筆スピードと正確性が向上する。
  3. **読者ファーストの姿勢が身につく**: 執筆者の心理状態から離れ、読者視点・第三者目線で客観的に文章を見直す習慣ができる。
- **チェックのコツ（「時間を置いてから」行う）**:
  - 執筆直後は脳が文章を勝手に補完してしまい間違いに気づきにくいため、数時間〜1日程度「時間を置いてから」チェックするのが最も効果的。
  - PCの編集画面だけでなく、スマホの実機・プレビュー画面で客観的に見直す。

## 🛠 具体例・実践パターン (Examples, Cases & Applications)

### 📋 ブログ記事公開前チェックリスト 25項目（7カテゴリ）

#### 1. タイトルを魅力的にするための3項目

- [ ] **検索キーワードが含まれているか**: 狙っているメインキーワードおよび関連キーワードが自然な形で含まれているか。
- [ ] **タイトルの文字数は30字前後か**: 検索結果一覧で途切れずに表示される文字数（30〜35文字程度）に収まっているか。重要キーワードは前半に配置する。
- [ ] **タイトルで記事の内容がわかるか**: 誇大表現にならず、読者が「自分の悩みを解決してくれる記事だ」と一目で理解できるか。

#### 2. リード（導入文）で本文に誘導するための3項目

- [ ] **読者への共感が示されているか**: ターゲット読者の悩みや課題に寄り添う言葉から始まっているか。
- [ ] **要約や読むメリットが書かれているか**: この記事に何が書かれており、読むことでどんな悩みが解決するのか（ベネフィット）が提示されているか。
- [ ] **300字～400字で簡潔にまとめられているか**: 導入が長すぎて本文到達前に読者が離脱しないよう、コンパクトにまとまっているか。

#### 3. 論理的で説得力のある構成にするための3項目

- [ ] **記事の流れが自然か**: 「導入 → 主題 → まとめ」など、論理の展開に破綻や脈絡のない飛躍がないか。
- [ ] **主題となる内容の登場が遅すぎないか**: 読者が最も知りたい結論やメインテーマが前置きに埋もれず、早い段階で提示されているか。
- [ ] **主題となる内容がもっとも充実しているか**: 補足トピックばかりが長くなり、メインの主題が薄くなっていないか。

#### 4. 最適な見出し構成にするための3項目

- [ ] **見出しに具体性があり、内容が想像できるか**: 見出し（H2/H3）を読むだけで各セクションの要点が理解できるか。
- [ ] **キーワードを入れすぎていないか**: 不自然に検索キーワードを詰め込んで読みにくくなっていないか。
- [ ] **H2やH3の階層構造が正しいか**: H2（大見出し）の中にH3（中見出し）を配置するなど、正しく包含関係が整理されているか（デザイン目的での見出しレベルのスキップは不可）。

#### 5. ストレスなく読める本文にするための6項目

- [ ] **誤字・脱字はないか**: 誤変換、入力漏れ、助詞（てにをは）のおかしな点がないか。
- [ ] **読みやすい文章の原則が守られているか**:
  - 1文の長さは60文字程度を目安に短く分割されているか。
  - 同じ文末表現（「〜です」「〜ます」等）が3回以上連続していないか。
  - 専門用語には噛み砕いた解説や補足が付けられているか。
- [ ] **強調したい語句が適切に装飾されているか**: 太字や装飾文字で強調されているか（色数は2色程度に抑え、1見出しあたり1〜2箇所程度にとどめる）。
- [ ] **箇条書きや表を使って理解をサポートしているか**: 3つ以上の並列情報や比較情報は、文章の羅列ではなく箇条書きやテーブルを活用しているか。
- [ ] **必要な内部リンクが貼られているか**: 関連する詳細解説記事への内部リンクが適切に設置されているか。
- [ ] **画像が内容の理解を助けているか**: 文字だけでは理解しにくい概念に図解やスクリーンショットが配置されているか。

#### 6. スマホからも見やすくするための2項目

- [ ] **読みやすい改行、段落になっているか**: スマホ表示時に不自然な位置で改行されていないか。1段落が長すぎて画面を埋め尽くしていないか（2〜3行ごとに改行・空行を入れる）。
- [ ] **画面が装飾のない本文だけ埋まっていないか**: スマホの小さな画面が文章のみで埋まって重苦しくならないよう、画像・箇条書き・装飾を適度に入れているか。

#### 7. SEOのための基本設定5項目

- [ ] **メタディスクリプションが設定されているか**: 検索画面のタイトル下に表示される要約文（80〜120文字程度）が正しく記入されているか。
- [ ] **画像が最適化されているか**:
  - 画像容量は軽量化されているか（1枚あたり200KB以下が目安）。
  - ファイル名は内容がわかる英字表記になっているか（`IMG_001.JPG` 等は避ける）。
  - altテキスト（代替テキスト）が日本語で適切に記述されているか。
- [ ] **パーマリンクが設定されているか**:
  - 日本語ではなく英数字（kebab-case）で記事内容を表すシンプルなURLに指定されているか。
  - 日付を含まない「投稿名のみ」の構造になっているか。
- [ ] **カテゴリーやタグが設定されているか**: 適切なカテゴリーに分類され、関連するタグが付与されているか。
- [ ] **アイキャッチが設定されているか**: 一覧やSNS共有時に表示されるサムネイル画像が設定されているか。

## ⚠️ 注意点・リスク・懸念事項 (Risks, Trade-offs & Considerations)

- **パーマリンクの公開後変更リスク**:
  - パーマリンク（記事URL）を公開後に変更すると、**SEO評価や被リンク、SNSシェア数がリセットされる**ため、必ず【公開前】に英語でパーマリンクを設定しておくこと。
- **装飾過多による視認性低下**:
  - 太字・赤文字・マーカーなどを使いすぎると、重要なポイントが分からなくなり逆に読みづらくなる。強調する色は2色まで、各見出し1〜2箇所程度に留める。
- **見出し階層（Hタグ）の誤用**:
  - デザイン上の理由（文字サイズや装飾の好み）でH2をスキップしてH3を使うような使い方は、SEO（クローラーの構造理解）においてマイナスとなるため厳禁。
- **「直後チェック」の罠**:
  - 執筆直後は記憶や意図が頭に残っているため、間違いを見落としやすい。一晩置くか、別のタスクを挟んでから校正を行う時間を確保すること。
