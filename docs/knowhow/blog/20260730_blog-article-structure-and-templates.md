## 💡 要点・コアコンセプト (Key Concepts / Summary)

- **ブログ記事の基本3パート構成**:
  1. **導入部分（リード文）**: 読者の関心を引きつけ、記事を読み進める意欲を高める最も重要要素。
  2. **記事本文部分**: 読者の悩みや疑問を解決するメインパート。見出し構造と論理展開が重要。
  3. **まとめ部分**: 要点を再確認させ、満足度を高めたうえで次にとるべき行動（CTA）へ誘導する。
- **文章展開の型「PREP法」**: 結論（Point）→ 理由（Reason）→ 具体例（Example）→ 結論（Point）の順番で記述し、説得力と理解しやすさを最大化する。
- **適切な見出し階層**: `h1`（記事タイトル・1回のみ）から `h2` → `h3` → `h4` の正しい順序で入れ子構造を作る。

## 🛠 具体例・実践パターン (Examples, Cases & Applications)

### 1. 導入部分の書き方（5ステップテンプレート）

導入部分（リード文）は以下の5つのステップで構成する。

| ステップ | 内容 | 記述例 / 役割 |
| :--- | :--- | :--- |
| **Step 1** | **悩み・疑問の提示** | 「〜という疑問や悩みを抱えていませんか？」<br>→ 読者の悩みに共感し関心を引きつける |
| **Step 2** | **解決策の提示** | 「この記事では〜の具体的方法・型を解説します」<br>→ 簡潔に解決できる手段があることを提示する |
| **Step 3** | **ベネフィットの提示** | 「読めば〜ができるようになります / 迷わず書けるようになります」<br>→ 記事を読むことで得られる将来的なメリットを示す |
| **Step 4** | **根拠・信頼性の提示** | 「〇〇件以上の記事執筆実績」「〇日間の徹底調査」<br>→ 実績やかけたリサーチ量で記事の説得力を補強する |
| **Step 5** | **記事内容の一言要約** | 「今回は、初心者向けの情報発信テンプレートを解説します」<br>→ 記事の全体像を示し安心して読み進められるようにする |

> 💡 **読者の悩みをリサーチする3つの方法**:
>
> 1. **関連キーワード**: 「ブログ 書き方」などの検索キーワードから疑問を推測する。
> 2. **Yahoo!知恵袋・Q&Aサイト**: ユーザーが実際に使っている悩み・言葉を収集する。
> 3. **SNS検索**: ハッシュタグ（`#ブログ` 等）でリアルタイムな困りごとや投稿を探す。

### 2. 記事本文の書き方（PREP法）

本文のトピックごとに PREP 法を用いて記述する。

| 要素 | 英語 | 役割・表現例 |
| :--- | :--- | :--- |
| **P** | **Point (結論)** | 「記事を書く際はPREP法を使います。」<br>冒頭で要点を伝え、流し読みでも理解できるようにする |
| **R** | **Reason (理由)** | 「なぜなら、話の道筋が分かりやすくなり説得力が増すからです。」<br>結論の根拠を示し、離脱を防ぐ |
| **E** | **Example (具体例)** | 「たとえば、プレゼンや学術論文でも広く使われています。」<br>数字や具体的な状況を示してイメージを具体化する |
| **P** | **Point (再結論)** | 「なので、ブログでもこの型を使うことで内容が正確に伝わります。」<br>最後にもう一度強調し、記憶に定着させる |

```markdown
<!-- 本文ブロックの記述テンプレート例 -->
### [h2見出し] トピック名
（結論）〇〇を行うには、▲▲のステップが最適です。
（理由）なぜなら、〇〇の作業負担を半減させることができるからです。
（具体例）たとえば、実際の実装例として以下のようなケースが挙げられます。
（再結論）したがって、まずは▲▲のステップから始めることをおすすめします。
```

### 3. 見出し（hタグ）の階層構造規則

- **h1**: 記事タイトル（1ページにつき1回のみ使用）
- **h2**: 各メインセクション（導入・大トピック・まとめ）
- **h3**: h2の中の大見出しを補足・分解する中見出し
- **h4 / h5**: さらに詳細な要素を分ける小見出し

```markdown
# 記事タイトル（h1）

## 1. 大トピックA（h2）
### 1-1. 中トピックA-1（h3）
#### 1-1-1. 小トピック（h4）
### 1-2. 中トピックA-2（h3）

## 2. 大トピックB（h2）

## 3. まとめ（h2）
```

### 4. まとめ部分の書き方（3ステップテンプレート）

| ステップ | 内容 | 目的・アプローチ |
| :--- | :--- | :--- |
| **Step 1** | **本文の要約・おさらい** | 本文の要点を箇条書きなどで簡単に復習し、記憶に定着させる |
| **Step 2** | **解決の再確認** | 悩みが解消されたことを提示し、読者の読後満足度・納得感を高める |
| **Step 3** | **CTA（Call to Action）の設置** | 次に読者が取るべき行動（関連記事へのリンク、商品/サービス案内等）を促す |

## ⚠️ 注意点・リスク・懸念事項 (Risks, Trade-offs & Considerations)

- **適さない記事タイプ**:
  - 個人・日常の「日記」記事
  - 順を追って手順だけを淡々と説明する「ツールの操作ガイド・チュートリアル」記事
  - （これらには必ずしもPREP法や5ステップ導入が最適とは限らない）
- **PREP法の柔軟な運用**:
  - 全ての段落で厳密に「具体例」や「再結論」まで書くと冗長になる場合がある。
  - 最低限 **「結論 (Point)」＋「理由 (Reason)」** のペアはセットで残し、場面に応じて調整する。
- **リード文での自己紹介過多**:
  - 読者は筆者の詳細な経歴に最初から興味があるわけではない。長すぎる自己紹介は離脱原因になるため避ける。
