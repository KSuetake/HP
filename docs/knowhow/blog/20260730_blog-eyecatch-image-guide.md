## 💡 要点・コアコンセプト (Key Concepts / Summary)

### 1. アイキャッチ画像の役割と3大効果

- **直感的な理解・記憶定着**: 文字テキストよりも視覚情報（画像）の方が一瞬で記事テーマを理解でき、読者の記憶に残りやすい。
- **CTR（クリック率）の向上**: SNS（X、Facebookなど）でのシェアイメージ（OGP）や、ブログ記事一覧で読者の目を引き、クリック率を高める。
- **サイト内回遊率の向上・離脱防止**: 関連記事一覧などで魅力的なアイキャッチが表示されることで、別記事への回遊を促し滞在時間を伸ばす。

### 2. アイキャッチ制作の基本スペック

- **標準推奨サイズ**: **横1200px × 縦630px**（アスペクト比 1.91:1 / 16:9 相当）。
- **選定理由**: 各種SNS（X等）のOGP表示で上下左右がトリミングされにくく、レスポンシブなブログ一覧画面でもバランスよく表示されるため。
- **ファイルサイズと最適化**: 表示速度の遅延（SEO低下）を防ぐため、品質を維持しつつ画像を圧縮し軽量化して運用する。

### 3. 視覚デザインにおける黄金原則

- **記事内容の1秒判別**: 主題（キーワード・ターゲット読者）を視覚的・文字で最も目立たせる。
- **高コントラストと可読性保障**: 背景画像と文字の同化を防ぎ、スマホ等の小さな画面でも一目で読める状態を作る。
- **統一感のあるカラーパレット**: 色数を絞り、ブログ全体のトーン＆マナーと合わせた色使いで専門性・信頼感を演出する。

## 🛠 具体例・実践パターン (Examples, Cases & Applications)

### 1. 背景画像と文字の可読性を高めるレイヤー構造テクニック

ツールの種類（Canva, Figma, Photoshop, PowerPoint等）を問わず活用できる、可読性向上・レイヤー配置の汎用テクニックです。

| 手法 | 具体的処理・設定値 | 効果・目的 |
| :--- | :--- | :--- |
| **半透明オーバーレイ（暗膜・明膜）** | 背景画像と文字の間に、黒または白の四角形シェイプを置き、**不透明度を40%〜60%**程度にする。 | 写真の雰囲気を残しつつ、背景のゴチャつきを抑えて文字の可読性を劇的に向上させる。 |
| **文字背後の帯・座布団（シェイプ）** | 文字の背景にのみ長方形や角丸の帯を敷く（単色または半透明）。 | タイトル内の特定の強調キーワードを局所的にくっきり際立たせる。 |
| **枠線（ストローク）付きフレーム** | 画像の四辺の内側に白やテーマカラーの枠線（太さ5〜10px程度）を配置する。 | デザイン全体の輪郭を締め、アイキャッチとしてのまとまりを与える。 |

### 2. アイキャッチ作成の5ステップ汎用ワークフロー

```
[Step 1] キャンバスサイズ設定
  └── 横1200px × 縦630px（または利用テーマの推奨サイズ）で作成開始

[Step 2] メインビジュアル / 背景素材の決定
  └── 記事テーマに合致する高品質な写真またはイラストを選択・配置

[Step 3] 可読性調整（レイヤー・オーバーレイ処理）
  └── 背景画像の上に半透明のシェイプ（黒/白）や文字座布団をレイヤーとして追加

[Step 4] キャッチコピー・文字要素の配置
  └── 記事タイトル全文ではなく「読者の目を引く要約キーワード」を太字・大サイズで配置
  └── 配色（メイン色・文字色・アクセント色）を統一

[Step 5] 複数端末プレビューと軽量化書き出し
  └── スマホ・PC両方での可読性を確認し、WebP / PNG / JPG として書き出す
```

### 3. 文字装飾とレイアウト・配色の実践ルール

- **フォント選び**:
  - **ゴシック体 / 太字サンセリフ**: スマホの小さな画面や低解像度でも文字が潰れにくく、視認性が抜群（基本推奨）。
  - **明朝体 / セリフ体**: 高級感、文芸、繊細さ、フォーマルさを表現したい場合に限定使用。
- **配色ルール（3色限定）**:
  - メインカラー（背景・ベース）：全体の60%
  - サブカラー（文字・フレーム）：全体の30%
  - アクセントカラー（最強調キーワード）：全体の10%
- **安全領域（セーフゾーン）の意識**:
  - 各種SNSやWordPressテーマによる端切れ（トリミング）を防ぐため、重要なテキストやメインイラストは**画面中心の80%エリア内**に収める。

### 4. WordPressでのアイキャッチ設定手順

1. **投稿編集画面を開く**: WordPressのブロックエディタ投稿画面へアクセス。
2. **サイドバー操作**: 右側設定パネルの「投稿」タブを選択。
3. **アイキャッチ画像の選択**: 「アイキャッチ画像」セクションで「アイキャッチ画像を設定」をクリック。
4. **画像のアップロードと設定**: 「ファイルをアップロード」から作成・軽量化した画像を選択し、右下の「アイキャッチ画像を設定」ボタンをクリック。
5. **保存と表示確認**: 記事を「下書き保存」または「更新」し、実際のプレビュー画面でレイアウト崩れがないか確認。

## ⚠️ 注意点・リスク・懸念事項 (Risks, Trade-offs & Considerations)

1. **文字情報の詰め込みすぎ（タイトル全文のそのまま配置）**
   - 記事タイトルをそのまま長々と記載すると、文字が小さくなりスマホや一覧ページで読めなくなる。
   - **対策**: タイトルから重要なキーフレーズ（15〜20文字程度）を抽出して大フォントで配置する。
2. **無圧縮画像によるページ表示速度低下（SEO・UX悪化）**
   - 高解像度・未圧縮の画像（数MBクラス）をアップロードすると、モバイル回線での読み込み時間が著しく増加する。
   - **対策**: 画像解像度を適正サイズにし、画像圧縮ツールやプラグイン等で数10KB〜200KB前後に軽量化する。
3. **文脈にそぐわない低品質素材の使用**
   - 解像度が低い（ぼやけている）画像や、記事テーマと全く関係ないフリー素材を使用すると、記事やサイト全体の信頼性が損なわれる。
   - **対策**: 記事テーマを端的に象徴する高品質なフリー写真・イラスト、または自作のオリジナル画像・スクショを使用する。
