## 💡 要点・コアコンセプト (Key Concepts / Summary)

ブログ執筆において最も重要な大原則は **「常に読者目線であること」**。自分の言いたいことや主観を一方的に発信するのではなく、読者の悩みや知りたいこと（ニーズ）に答えるコンテンツを作ることが成功の鍵となる。

ブログ執筆のプロセスは「執筆前」「本文執筆」「執筆後」の3フェーズ（全18項目）に分類できる。

```
【大原則】読者目線の徹底（誰のどんな悩みを解決するか）
  │
  ├── 1. 執筆前の準備（準備6つ）
  │     └─ ターゲット具体化 / ニーズ特定 / キーワード・タイトル / 構成案作成 / PREP法
  │
  ├── 2. 本文の執筆（テクニック10個）
  │     └─ ライティングルール / リード文後書き / 簡潔性 / 黄金比 / です・ます調 / 可視化（図解・箇条書き）
  │
  └── 3. 執筆後の仕上げ（推敲1つ）
        └─ 一晩寝かせてスマホ等の別端末で最終読み返し・修正
```

## 🛠 具体例・実践パターン (Examples, Cases & Applications)

### 1. ターゲット（ペルソナ）と悩みの具体化

万人に受ける記事を作ろうとすると、誰の悩みも解決できなくなるため、ターゲットは「特定の1人」に絞る。

- **× 悪い例**: 「ブログ初心者」
- **〇 良い例**: 「最近ブログを始めたものの、記事が最後までうまく書ききれなくて悩んでいる知人の山田さん」

### 2. 記事構成の基本（PREP法）

解説記事やノウハウ記事では、読者が一番求めている「結論」を最初に伝える。

1. **P (Point/結論)**: 1ヶ月で10kg痩せることに成功しました。
2. **R (Reason/理由)**: ダイエットのためにジョギングを毎朝20分間欠かさず行ったからです。
3. **E (Example/具体例)**: 最初はなかなか変化が出ませんでしたが、継続することで効果が現れました。
4. **P (Point/まとめ・再結論)**: 正しい習慣作りがダイエット成功に重要でした。

### 3. 高速執筆を可能にする3ステップ構成法

上坂徹氏の『10倍速く書ける 超スピード文章術』をベースにした構成作成プロセス。

- **STEP 1**: 記事の大枠の構成（見出し H2, H3 など）を決める。
- **STEP 2**: 原稿の元となる文章や思いついた情報を構成・推敲を気にせず「なぐり書き」して洗い出す。
- **STEP 3**: 洗い出した要素を最後に清書し、文章を組み立てる。

### 4. 主なライティングルールと文章調整

| 項目 | ルール・黄金比 | 実践例・注意点 |
| :--- | :--- | :--- |
| **文字比率** | **ひらがな 7割 / 漢字 2〜3割 / カタカナ 1割** | 漢字が連続しすぎると圧迫感が出るため、ペンで書けない難解な漢字はひらがな/カタカナにする |
| **一文の長さ** | **40文字〜80文字以内** | 長文は適切な位置で句点を打ち、2文に分割する |
| **語尾の重複** | **3回以上の連続NG** | 「〜です。〜です。〜です。」とならないよう表現を散らす |
| **語尾の統一** | **「です・ます」調で統一** | 「〜である。〜です。」の混用を防ぎ、親しみやすいトーンにする |
| **要素の箇条書き** | **ポイントが3つ以上ある場合** | 箇条書き（ul/ol）を使って視認性を高める |
| **装飾の制限** | **1見出しに0〜1箇所、全体で2種類まで** | 赤文字・マーカー等の乱用は重要ポイントが埋もれるため厳禁 |

## ⚠️ 注意点・リスク・懸念事項 (Risks, Trade-offs & Considerations)

- **情報の詰め込みすぎによる失敗**:
  - キーワードに関連するすべての情報を網羅しようとすると長文化し、読者が離脱する原因となる。
  - 10,000文字の雑多な記事より、1,000文字で読者の疑問に直球で答える記事の方が評価される。
- **SEOキーワードの過剰投入**:
  - 見出しや本文にキーワードを入れることは重要だが、不自然に詰め込んで文章の読みやすさを損なっては本末転倒。
- **執筆直後の即時公開リスク**:
  - 書いた直後は達成感や主観が入っているため、誤字脱字や説明不足に気づきにくい。一晩寝かせて、必ずスマホなどの別端末で第三者目線で読み返す。
