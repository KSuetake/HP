# STK Lab ( https://stk-lab.org/ )

> **知恵と技術とちょっとのやる気で、身のまわりの愛と平和を取り戻すための余裕を手に入れましょう**

`STK Lab` は、テクノロジーや日々の知恵を活用して、身のまわりに「余裕」と「愛と平和」を取り戻すための実験・発信を行う個人メディア / ブログです。

---

## 1. サイトコンセプト & 設立意図 (Concept & Purpose)

* **メインテーマ**: 知恵と技術で愛と平和を取り戻せ！
* **キャッチコピー / メッセージ**: 
  > 知恵と技術とちょっとのやる気で、身のまわりの愛と平和を取り戻すための余裕を手に入れましょう

### 🎯 設立における2つの意図
本メディアの運営には、明確な **2つの目的** があります。

1. 💰 **収益化・プロモーション軸 (Monetization & Promotion)**
   * Web上の一般読者を対象に、自作アプリの宣伝や価値あるアフィリエイトコンテンツの提供を通じて、メディアとしての収益化を図る。
2. 🤝 **ナレッジの体系化・身近な人への共有軸 (Personal Knowledge Base)**
   * 家族や友人など身近な人々にお勧めしたいことや、日頃から何度も話している知識・ノウハウを体系的に整理し、いつでも引き出せる「ナレッジの引き出し」として蓄積する。

### 💡 コンテンツ発信の基本スタンス
* たとえ短期的・直接的に収益へ繋がらなかったとしても、**「自分や身近な人々に真に活用してほしい・お勧めしたい情報」** は積極的に発信します。
* 身近な人に届く本質的な価値や信頼の積み重ねが、巡り巡ってWeb全体の読者の価値となり、持続的な収益化へも繋がっていくという好循環（愛と平和の還元）を目指します。

## 4. リポジトリ構造 & 執筆ワークフロー (Repository & Workflow)

本リポジトリは、記事の企画・執筆・ノウハウ蓄積およびAIアシスタントとの協調作業を行うための基盤です。

### リポジトリ構成
```
.
├── articles/                     # 記事原稿・アセットの管理（記事単位ディレクトリ）
│   ├── <記事スラッグ>/
│   │   ├── article.md            # 記事本文
│   │   ├── design.md             # 記事設計書
│   │   └── images/               # 記事固有の画像アセット（アイキャッチ・図解等）
│   ├── shopping-guide/           # お買いものシステム構築ガイド
│   └── youtube-curation-guide/   # YouTube超タイパ術
├── docs/
│   ├── knowhow/blog/             # ブログ執筆・SEO・構成等のノウハウ（ドキュメント集）
│   └── wordpress-mcp-operations.md # [WordPress MCP / REST API 運用ガイド](docs/wordpress-mcp-operations.md)（ドラフト運用・機能マトリクス）
├── scripts/                      # WordPress REST API 疎通・ドラフト投稿CLIスクリプト
└── .agents/
    └── skills/
        └── blog-assistant/       # ブログ記事の企画・執筆・推敲を支援するAIスキル
```

### 記事作成の流れ
1. **企画・構想**: コンセプト（「知恵と技術で余裕を取り戻す」）に沿ったテーマ・キーワード選定
2. **ノウハウ参照**: `docs/knowhow/blog/` 配下のノウハウや `blog-assistant` スキルを活用して構成案・骨子を作成
3. **執筆・推敲**: 可読性や説得力を意識した本文の執筆
4. **事前チェック & 独立二重監査**: 公開前チェックリストに基づき、メタ情報・見出し・リンク等を最終確認
5. **WordPress 下書き（Draft）登録**: `scripts/wp-draft-post.js` または MCP を介して安全にドラフト登録（※誤公開を防ぐためAPI経由では常に `status: draft` を強制、詳細は [WordPress運用ガイド](docs/wordpress-mcp-operations.md) 参照）
6. **目視プレビュー確認 & 手動公開**: WordPress 管理画面上でデザイン・装飾を確認後、手動で公開
7. **蓄積・フィードバック**: 得られた知見を `docs/knowhow/` やリポジトリへ記録・蓄積

## 5. 記事執筆時のチェックポイント (Editorial Checklist)

記事を増やす際は、常に以下の問いに立ち返ります。

- [ ] **コンセプトの一致**: その記事は「身のまわりの愛と平和を取り戻すための余裕」に繋がる知恵や技術を提供しているか？
- [ ] **設立意図との整合**: 身近な家族や友人へ胸を張ってお勧めできる「体系化された知恵」か、あるいは自作アプリ宣伝・アフィリエイト等の収益化に貢献するコンテンツか？
- [ ] **読者価値**: 単なる雑記にとどまらず、自作アプリの知見・ライフハック・書評など具体的な価値や気づきが含まれているか？
- [ ] **ノウハウの適用**: `docs/knowhow/blog/` にある書き方・構成・SEOガイドラインを意識できているか？
